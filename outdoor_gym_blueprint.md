| Dead Load (lumber) | ~15 psf | All members | Self-weight of structure |
| Live Load (deck) | 40 psf | Upper deck | Per IRC Table R301.5 |

| Dynamic Load | 150 lb | Monkey bars | Single-person dynamic |
| Dynamic Load | 300 lb | Dip stations | Single-person dynamic |

**POST CAPACITY CHECK — 6×6 Southern Pine #2 GC PT:**
- Axial capacity (48" embed + 14 ft tall = 176" unbraced length):
  - L/d = 176" / 5.5" = 32 (slender column)
  - Fa = 1,100 psi / 32² × 0.3 = ~400 psi adjusted
  - Pallow = 400 psi × 30.25 in² = ~12,100 lb per post
  - Total 4-post capacity: ~48,400 lb
  - Required (dead + live + snow): ~8,000 lb (adequate with 6× factor)

**BEAM CAPACITY CHECK — 4×6 Southern Pine #2 GC PT:**
- Span: 12 ft (Zone A), 10 ft (Zone B)
- Uniform load: 40 psf live + 30 psf snow + 15 psf dead = 85 psf
- Tributary width (Zone A): 6 ft (half of 12 ft deck)
- w = 85 psf × 6 ft = 510 plf
- Mmax = wL² / 8 = 510 × 144 / 8 = 9,180 lb-ft
- Fb = 1100 psi × 1.15 (snow) = 1265 psi
- Srequired = M / Fb = 9,180 × 12 / 1265 = 87 in³
- Sprovided (4×6) = 30.66 in³ — **INSUFFICIENT**
- **SOLUTION:** Use 6×6 beam instead (S = 51.12 in³) — **ADEQUATE** (87/51.12 = 1.7, use double 2×6 or single 6×6)
- **FINAL:** Use single 6×6 for main beams (D1–D8)

3. **Final:** After all work complete including finishes

**Timeline:**
- Application processing: 5–10 business days
- Permit card issued before work begins
- Inspections must be scheduled in advance

## A8. CONSTRUCTION CHECKLIST

### PRE-CONSTRUCTION
- [ ] Call 811 (Massachusetts utility locators) — **minimum 3 business days**
- [ ] Obtain zoning determination from Bridgewater Building Dept
- [ ] Complete Homeowner Waiver Form (if owner-builder)
- [ ] Submit online permit application with full set of drawings
- [ ] Receive Building Permit card — **do not start work without it**
- [ ] Mark post locations with spray paint
- [ ] Verify property lines and setbacks match this plan
- [ ] Order all materials per Bill of Materials (BOM)
- [ ] Apply wood preservative to all cut ends before construction

### FOUNDATION
- [ ] Dig all 8 footings to 48" depth minimum
- [ ] Verify footing spacing matches drawing (Zone A: 12' × 12', Zone B: 10' × 5')
- [ ] Add 2" gravel base to each hole
- [ ] Schedule footing inspection with Bridgewater Building Dept
- [ ] Pour concrete — verify 3000 psi mix, 5% air entrainment
- [ ] Cure minimum 72 hours before framing
- [ ] Email as-built photos to building@bridgewaterma.org

### FRAMING
- [ ] Set posts plumb within ¼" in 10 ft
- [ ] Verify all posts are square (diagonals equal)
- [ ] Install post connectors (Simpson GB663 or HD8)
- [ ] Install beams — verify level within ¼" in 10 ft
- [ ] Install cross-braces at 45°
- [ ] Install upper deck joists at 16" OC
- [ ] Install deck boards — ¼" gap between boards
- [ ] Schedule framing inspection
- [ ] Verify all connections are tight

### EQUIPMENT
- [ ] Install pull-up bar — test with 200 lb dynamic load
- [ ] Install monkey bar rungs — test each rung with 150 lb
- [ ] Install dip station — verify both heights level
- [ ] Install rope tower — secure top and bottom
- [ ] Install swing chains — verify S-hook security
- [ ] Install TRX/gymnastic rings — verify carabiners locked

### FINISH
- [ ] Install safety netting — check all ties are tight
- [ ] Install shade sails — tension with turnbuckles
- [ ] Install climbing holds — verify lag bolt security
- [ ] Apply stain/sealant — minimum two coats
- [ ] Install ground surface — rubber mulch/tiles
- [ ] Apply copper naphthenate to all field-cut ends

### FINAL
- [ ] Call for final inspection
- [ ] Verify all bolts torqued and secured
- [ ] Verify netting gaps < 2"
- [ ] Verify overhead clearance > 15 ft
- [ ] Schedule email final inspection to building@bridgewaterma.org
